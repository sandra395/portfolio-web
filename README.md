# Sandra Barbosa - Portfolio Website

A modern, responsive portfolio website showcasing my journey as a Junior Frontend Developer, built with Next.js, TypeScript, and Tailwind CSS.

## 🚀 Live Demo

[View Portfolio](https://sandrabarbosa-portfolio.vercel.app/)

## 🎯 What You'll Find

- **About Me** - My background transitioning from education to tech
- **Technical Skills** - Frontend technologies and tools I work with
- **Projects** - Full-stack applications including my Airbnb-style booking platform
- **Experience** - My journey through Northcoders bootcamp and beyond
- **Contact** - Ways to connect and collaborate

## 🛠️ Built With

- **Next.js 13** - React framework with App Router
- **TypeScript** - Type-safe development
- **Tailwind CSS** - Utility-first styling
- **shadcn/ui** - Modern UI components

## ✨ Key Features

- **Fully Responsive** - Optimized for mobile, tablet, and desktop
- **Performance Focused** - Fast loading with Next.js optimization
- **Accessible Design** - Accessibility-minded
- **Modern UI/UX** - Clean, professional interface
